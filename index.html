Den här versionen använder webbläsarens egen taligenkänning för svenska. Den är byggd för vuxenröster och lägger 300–800 ms i latens — tillräckligt för att pröva om samspelet fungerar, inte för att bedöma hur bra spårningen kan bli. Mätningen längst ner räknar tiden från att rösten startar till att markören flyttar sig.

Kör sidan via http://localhost i stället för att öppna filen direkt, så slipper du frågan om mikrofonen varje gång: python3 -m http.server 8000 i mappen där filen ligger.

Fler svenska röster laddas ner under Systeminställningar › Hjälpmedel › Talat innehåll › Hantera röster. Starta om webbläsaren efteråt.
